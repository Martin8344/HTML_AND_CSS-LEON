# LEON - Agency Landing Page

A clean, responsive landing page for a creative agency. Built with HTML and CSS.

🔗 **Live Demo:** https://martin8344.github.io/HTML_AND_CSS_LEON/

## Features
- Fully responsive design for mobile, tablet & desktop
- Modern landing page with Services, Portfolio, About, Contact sections
- Clean and minimal UI
- Built with pure HTML & CSS

## Technologies Used
- HTML5
- CSS3

## How to Run
1. Clone the repo
2. Open `index.html` in your browser
